# 零废弃数字化知识库「对外版」

> P3P4 四组拼装协作主仓库 · 2026-10-03 重建的干净版

**产品是什么**：把钉钉里跑通的零废弃知识库（400+ 份公开资料 + AI 问答），搬到一个能对外分享的网站上。公益从业者、研究者、公众点开链接就能搜资料、看原文、下载、问 AI。

**技术架构**（一句话）：门户自己写（Vue3 前端 + FastAPI 后端）＋ AI 问答引擎直接用腾讯开源的 WeKnora（接阿里云百炼 Qwen）。公网只暴露门户，引擎藏在服务器内网。

## 👤 我是队友，我要干活

**你只需要做三件事，全程不用敲命令、不用学 Git：**

1. **领任务** —— 打开 [Issues 页签](https://github.com/a3230038469/widework-v2/issues)，筛选标签 `状态/待领取`，挑一个（新手优先挑 `难度/易`）。在 Issue 右侧点 Assignees 选自己，把标签 `状态/待领取` 改成 `状态/进行中`，评论一句「我认领」。
2. **干活** —— 把任务 Issue 的内容**复制进你平时用的 AI 助手**（WorkBuddy 等），让它按 Issue 里的「交付物」和「验收标准」做。
3. **交付** —— 在 GitHub 网页上把文件拖进对应目录 → 提交（说明里带 `#任务号`）→ 发 Pull Request。

> **怎么让 AI 助手全程接管？** 把这句话发给它（把任务号换成你的）：
>
> ```
> 读 https://github.com/a3230038469/widework-v2/blob/main/AGENT.md，按里面的流程帮我完成 issue #<任务号> 并交付。
> ```
>
> 它读完就知道全流程了，会替你领、干、测、整理成可交付的样子。

## ⚡ 四条铁律

1. 提交说明 / PR 标题**必须带 `#任务号`**（否则贡献统计不到、任务不会自动关闭）
2. **只改自己任务目录里的文件**（越界 = 拼装事故，PR 直接退回）
3. **字段名 / 接口路径 / 事件名只能抄契约**，不许自己发明
4. **`main` 分支不许直接提交**，一律走 Pull Request
