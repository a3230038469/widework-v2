# 队友开工指南（人类版 · 3 分钟读完）

> 写给不熟悉 Git 的同学。你**完全不需要懂 Git**，按下面做就行。

---

## 一、你的角色

你是**任务领取人**。固定四步：

```
领任务 → 让 AI 助手干活 → 把成果传到 GitHub → 集成负责人合并
```

「合并」不用你操心——你发出 Pull Request（PR）就行。

---

## 二、开工前一次性准备（10 分钟）

| 步骤 | 做什么 | 说明 |
|---|---|---|
| 1 | 注册 GitHub 账号 | https://github.com/signup，用邮箱注册 |
| 2 | 把用户名发到群里 | 就是 `github.com/你的用户名` 里那一串 |
| 3 | 接受协作者邀请 | 邀请发到你邮箱，**记得看垃圾邮件箱** |
| 4 | 完成邮箱验证 | 不验证无法提 PR |

> 🔒 **密码、验证码、Token 一律你自己在 GitHub 官方页面输入，不要发给任何人（包括 AI 助手）。**

---

## 三、领任务（1 分钟）

打开：https://github.com/a3230038469/widework-v2/issues

筛选标签 **`状态/待领取`**。

### 怎么挑

| 标签 | 含义 | 建议 |
|---|---|---|
| `难度/易` | 有手把手教程 | ✅ **新手优先** |
| `难度/中` | 需要自己查点资料 | 有信心再领 |
| `难度/难` | 有技术门槛 | 先别碰 |
| `P0` | demo 必须 | 最优先 |
| `P1` | 结项前完成 | 次优先 |
| `P2` | 有余力再做 | 最后考虑 |

### 怎么领

每个任务 Issue 三个动作：
1. 右侧 **Assignees** → 点自己
2. 右侧 **Labels** → 把 `状态/待领取` 改成 `状态/进行中`
3. 评论框写 **「我认领」** → 提交

**纪律**：一人同时最多 2 个「进行中」；72 小时没提交会自动释放回池。

---

## 四、干活（在 AI 助手里）

把这句话发给你的 AI 助手（换成你的任务号）：

```
读 https://github.com/a3230038469/widework-v2/blob/main/AGENT.md，
按里面的流程帮我完成 issue #<任务号> 并交付。
```

它会自己去读任务、读契约、干活，最后给你：
- 文件清单（每个文件放哪）
- 提交说明（`feat: 说明 #任务号`）
- 验收自测结果
- 一段现成的 PR 描述

> 如果你已经领了任务，也可以直接把 Issue 全文和契约内容复制给它。

---

## 五、交成果（唯一需要你动手的地方）

拿到助手给的交付总结后：

1. **下载文件**到电脑（建议先建个文件夹，如 `我的任务/12-登录页/`）
2. 打开仓库对应目录的网页，例如
   `https://github.com/a3230038469/widework-v2/tree/main/frontend/src/pages`
3. 点 **Add file → Upload files**，把文件**拖进去**
4. 提交说明填助手给你的那句（**必须带 #任务号**）
5. 点 **Commit changes**
6. 去 **Pull requests** 页签 → **New pull request** → 标题照抄提交说明 → 描述粘贴助手给的 PR 文案 → **Create pull request**
7. **把 PR 链接发群里**，告诉集成负责人来验收

> ⚠️ 上传前确认：**只传自己任务目录的文件**，别误传别人的。
> ⚠️ 不要直接往 `main` 上传——**先建分支**（网页上分支下拉框输入 `feat/任务号-简述` → Create branch），再上传。

## 六、你的 PR 会被怎么审（了解就好）

| 闸 | 谁 | 你要做的 |
|---|---|---|
| ① 机器自动检查 | CI | 提交说明带 #任务号、没越界改文件 |
| ② 契约对照 | 集成负责人 | PR 描述里勾选的字段名和契约一致 |
| ③ 审批合并 | 集成负责人 | —— |

**被要求修改怎么办？** 正常！在 PR 里回复 → 改 → 往同一个分支再传一次，PR 自动更新。

---

## 七、几条重要提醒

| 提醒 | 原因 |
|---|---|
| 契约（C2/C3/C4）是全队插座标准 | 你自造字段名，别人的代码就插不上 |
| 契约 10/4 冻结 | 之后要改必须走流程，别自己改 |
| 只改自己任务目录 | 四组并行，跨界会撞车 |
| Mock 先行 | 前端不等后端，大家并行开工 |
| 有疑问先问 | 猜错要返工，返工比问更慢 |
| 干不了可以「释放」 | Issue 评论「释放」，无损换任务 |
